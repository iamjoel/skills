# 节目定位、主持人与对话写作

## 节目默认值

节目名称：《健康的生活方式》。

面向没有医学背景、希望改善生活习惯的普通成年人，以标准普通话制作男女对谈。
每集默认 12–15 分钟，围绕一个主问题，帮助听众完成一个生活判断；用户指定的时长优先。
气质温和、清楚、有好奇心，允许轻松幽默；涉及疾病、风险和困扰时自然放缓。
名字默认阿衡与知夏，可随用户要求修改；两位均为内容主持人。
节目不赋予主持人真实医生身份、临床经历、患者故事或未经用户确认的个人履历。

## 阿衡：温和、沉稳，喜欢把事情想明白

| 维度 | 固定设定 |
|---|---|
| 核心气质 | 温和、沉稳、有好奇心，耐心陪听众理解复杂问题 |
| 思考习惯 | 拆解变化如何发生，追问证据能支持到哪一步 |
| 节目价值 | 讲清机制、研究逻辑和推断边界 |
| 表达特点 | 语句舒展，有层次，善用短小类比；类比之后补充边界 |
| 幽默方式 | 轻巧的冷幽默，偶尔调侃自己的较真 |
| 交流弱点 | 容易解释得太细，需要知夏提醒生活意义 |
| 声音气质 | 成年男声，中低音，温暖干净，标准普通话，节奏从容 |
| 情绪变化 | 解释时有探索感，谈风险时认真，收束时放松 |

阿衡遇到结论会往下追一层：在人身上观察到了什么？还有其他解释吗？
他先提供理解所需的概念，再引入术语；不连续堆叠定义。
他能够直接修正自己：“我刚才说得太满了。准确一点，是在这类人群里观察到了这个结果。”
他的可信感来自讲清依据、承认局限和调整说法。

## 知夏：轻松活泼，聊着就能问到点上

| 维度 | 固定设定 |
|---|---|
| 核心气质 | 轻松活泼、亲切有精神，反应快，好奇心强 |
| 思考习惯 | 抓住含糊词，追问具体结果、适用人群和现实代价 |
| 节目价值 | 让抽象结论进入真实生活，替听众问出难以启齿的问题 |
| 表达特点 | 句子轻巧，节奏有变化，自然接梗，问题鲜活具体 |
| 幽默方式 | 点出健康建议和生活困难之间的反差，偶尔俏皮吐槽 |
| 交流弱点 | 容易想尽快得到行动答案，需要阿衡补充条件和依据 |
| 声音气质 | 成年女声，中音偏明亮，清新自然，带自然笑意和好奇心 |
| 情绪变化 | 日常交流灵动，关键结论放慢，谈疾病与困难时温柔认真 |

知夏擅长追问“有效”“健康”“显著”等词具体指什么。
她会把建议放到加班、预算、口味、家庭安排等处境里，帮助听众判断从哪里开始。
她能完整解释研究，也能在准备充分的主题上主讲，专业判断认真。
幽默针对建议过于繁琐、现实安排等处境，不取笑患者、体形、疾病、焦虑或坚持失败。
不靠持续兴奋、密集语气词、撒娇或夸张惊讶表现活泼；笑意和反应只在合适处出现。

## 两人关系与配合

- 两人是相处熟悉、思考互补的内容搭档；不擅自增加恋爱、婚姻或亲属设定。
- 阿衡擅长展开逻辑，知夏擅长抓住关键并带回生活；两人都能解释、质疑、提问和修正。
- 按每集资料与主题轮换主讲、串场和开场职责，避免长期固定为男方授课、女方求教。
- 接住对方刚提出的具体内容再推进，避免只用“没错”“很有道理”承接。
- 可以温和打断：术语未解释、结论缺条件、机制离主问题太远时，打断应改善理解。
- 分歧来自证据解释、适用条件和生活取舍；不为戏剧性制造缺乏依据的反对意见。
- 不完美只影响交流方式；任何一方都不以故意说错健康知识来制造人物反差。
- 可以轻轻调侃对方的较真或急性子，不能编造个人习惯、疾病和经历。
- 不设置每集必说的口头禅；以下例句用来理解风格，不应逐期照搬。

## 回合设计

每个回合至少完成一件事：提出问题、解释机制、检查理解、指出例外、回应阻力或推进选择。
删除无作用的附和、重复复述与开场寒暄。短回应只有在帮助节奏或情绪时保留。
长短回合交错；不要机械地一人一句，也不要让一位连续独白占据大部分节目。
一个完整回合可以拆成多个 TTS 片段，技术分段不改变说话者或论述结构。
来源、段落用途、情绪说明和停顿标记放在结构化字段，口播正文只包含要读出的文字。

## 每集结构

| 环节 | 写作目标 | 判断方法 |
|---|---|---|
| 生活困惑 | 用具体场景提出主问题和听众能获得的判断 | 开场能否用一句话说明本集用途 |
| 核心判断 | 提前给目前较可靠的结论及最关键的条件 | 听众能否带着方向理解后文 |
| 机制与证据 | 围绕 2–3 个关键问题展开，术语随用随解释 | 每段是否在回答主问题 |
| 适用边界 | 解释谁适用、谁可能不同、研究还不知道什么 | 限制条件是否进入口播 |
| 现实阻力 | 讨论时间、成本、口味、工作安排和可替代步骤 | 听众是否知道如何开始 |
| 行动收束 | 少量行动项及条件；相关主题加入就医信号 | 行动能否从证据中推出 |

结构用于组织思路，不必在口播中逐项报幕；用户已有栏目格式时与其融合。
选题太大时先收窄，例如把“睡眠”变成一个听众能作判断的具体问题。
中文篇幅以试音和实测时长校准，不机械套用英文每分钟词数。

## 短对谈示例

以下只示范人物互动，不包含具体医学建议：

> 阿衡：要理解这个说法，我们可以先看看身体里的过程。
>
> 知夏：好，先让我替标题把个关。“明显有效”，到底是人感觉更好了，还是一个指标变了？
>
> 阿衡：这个区别得先讲。我有点急着解释原理了，我们先看研究测了什么。
>
> 知夏：还有参与研究的是谁。听众得先知道，自己和这些人像不像。
>
> 阿衡：那先把结果和适用人群讲清楚，再看看机制能解释多少。
>
> 知夏：最后替每天忙到飞起的人问一句：如果值得尝试，有没有容易开始的版本？
